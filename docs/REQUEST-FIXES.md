## Межі

- LastWriteTime застосовується до PNG/PDF **всередині ZIP після розпакування**. Окреме датоване скачування — однофайловий ZIP. Браузер не може встановити OS mtime для прямого download; CreationTime і дата контейнера ZIP не підміняються.
- ZIP використовує timezone-less київський wall-clock час, точність 2 секунди. ISO instant у звіті та історії точніший. Вибрана дата не змінює серверний час створення і 30-денний retention.
- Старі записи без `batch_id` лишаються окремими: надійних даних про початкові списки немає. Нові запуски групуються. Незавершений пакет містить лише фактично успішні файли.
- Сумарний браузерний ZIP обмежено 250 MiB. Більші пакети потрібно скачувати окремо. Генерація потребує відкритої вкладки; background queue не додавалась.
- S3 batch listing: 2 key-list scans та приблизно один summary GET на пакет замість GET кожного файла. Detail/concurrent fallback має максимум 8 S3 readers. Перевірено контрактними stub-тестами, не живим bucket.
- Публічний Vercel, реальні S3/R2/CORS, cold start і комплексний accessibility-аудит не перевірені.
